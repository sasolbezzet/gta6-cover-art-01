An offline, browser-based multi-panel cover art and poster generator designed for the launch of **Grand Theft Auto VI**.

## Features
- **Multi-Panel Layouts:** 4-panel classic comic grid, 3-panel split hero, single full-bleed hero, and 5-panel montage with dark border gutters.
- **Vice City Color Grading:** Dynamic LUT filters including Neon Sunset, Golden Hour, Vice Night, and Retro Inked.
- **Any Photo Support:** Upload any custom image or choose from high-res presets with per-panel zoom and crop controls.
- **Genre Lettering:** Stylized bold typography with outer stroke outlines, deep drop shadows, and neon script subheaders.
- **Multi-Format Lossless Export:** One-click lossless PNG export for Square (1080x1080), Portrait (1080x1350), and Widescreen (1920x1080).
- **100% Offline & Private:** Client-side HTML5 Canvas processing with zero network requests or telemetry.

## Quick Start
```bash
node serve.ts --port 8080
```
Open [http://localhost:8080](http://localhost:8080) in desktop Chrome.

## Build Dossier
```bash
MAKEFUN_OUTPUT_DIR=out node main.ts
```
